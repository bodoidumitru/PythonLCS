Этот код состоит из трех частей:

    find_lcs — алгоритм поиска наибольшей общей подпоследовательности (LCS) для двух строк.

    analyze_csv — чтение файла, применение алгоритма к каждой строке таблицы и сохранение результата.

    Запуск — вызов функции.

Часть 1: Импорт и функция find_lcs
python

import pandas as pd

    Что делает: Подключает библиотеку pandas, которая умеет работать с таблицами (CSV, Excel). Мы будем давать ей сокращенное имя pd, чтобы не писать pandas каждый раз.

python

def find_lcs(text1, text2):

    Что делает: Объявляет функцию (def) с именем find_lcs. Она принимает две строки (text1 и text2) и будет возвращать их общую подпоследовательность.

python

    # Создаем таблицу для вычисления длины LCS
    n = len(text1)
    m = len(text2)

    Что делает: Считает длину первой строки (n) и второй (m). Это нужно, чтобы знать размер таблицы.

python

    dp = [[0] * (m + 1) for _ in range(n + 1)]

    Что делает: Создает двумерный список (матрицу/таблицу), заполненный нулями.

    Разбор:

        [0] * (m + 1) — создает список из m+1 нулей (это будет одна строка таблицы).

        for _ in range(n + 1) — повторяет это n+1 раз (создает n+1 таких строк).

        Зачем +1? Нужна дополнительная строка и столбец сверху и слева, чтобы не выходить за границы массива, когда мы будем обращаться к dp[i-1][j-1].

        Смысл: dp[i][j] будет хранить длину LCS для первых i символов text1 и первых j символов text2.

python

    # Заполняем таблицу
    for i in range(1, n + 1):
        for j in range(1, m + 1):

    Что делает: Два вложенных цикла. Мы проходим по каждой ячейке таблицы. Начинаем с 1, потому что нулевая строка/столбец — это "пустые" строки (база).

python

            if text1[i - 1] == text2[j - 1]:

    Что делает: Проверяет, совпадают ли текущие символы.

    Почему i-1 и j-1? Потому что индексы в Python начинаются с 0, а наша таблица dp имеет сдвиг на 1 (нулевая строка — пустая). То есть i=1 в цикле соответствует text1[0].

python

                dp[i][j] = dp[i - 1][j - 1] + 1

    Что делает: Если символы совпали, мы берем значение из диагонали (верхний левый угол) и прибавляем 1. Это значит: "длина LCS до этих символов + 1 новый совпавший символ".

python

            else:
                dp[i][j] = max(
                    dp[i - 1][j],
                    dp[i][j - 1]
                )

    Что делает: Если символы не совпали, мы не можем их использовать вместе. Мы берем максимум из двух вариантов:

        dp[i-1][j] — значение сверху (игнорируем текущий символ из text1).

        dp[i][j-1] — значение слева (игнорируем текущий символ из text2).

Восстановление самой строки

Таблица dp заполнена, но в ней только числа (длины). Нам нужна сама строка. Для этого идем по таблице назад.
python

    result = []

    Что делает: Создает пустой список, куда мы будем складывать найденные буквы (в обратном порядке).

python

    i = n
    j = m

    Что делает: Ставим указатели в правый нижний угол таблицы (конец обеих строк).

python

    while i > 0 and j > 0:

    Что делает: Идем назад, пока не дойдем до начала таблицы (пока индексы больше 0).

python

        if text1[i - 1] == text2[j - 1]:

    Что делает: Снова проверяем, совпадают ли символы (как при заполнении).

python

            result.append(text1[i - 1])
            i -= 1
            j -= 1

    Что делает: Если совпали — запоминаем этот символ, добавляя его в result. И двигаемся по диагонали влево-вверх (i и j уменьшаются на 1).

python

        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1

    Что делает: Если символы не совпали, смотрим, откуда пришло текущее число (сверху или слева).

        Если сверху число больше или равно (dp[i-1][j] >= dp[i][j-1]), двигаемся вверх (i -= 1).

        Иначе двигаемся влево (j -= 1).

    Мы как бы "отматываем" путь, который привел нас к максимальной длине.

python

    result.reverse()

    Что делает: Мы собирали буквы с конца строки к началу, поэтому список получился перевернутым. reverse() разворачивает его в правильный порядок.

python

    return "".join(result)

    Что делает: Превращает список символов (например, ['a', 'c', 'e']) в единую строку ("ace") и возвращает её.

Часть 2: Функция analyze_csv
python

def analyze_csv(input_file, output_file):

    Что делает: Функция принимает имя входного файла (где данные) и выходного (куда сохранить результат).

python

    # Читаем CSV
    data = pd.read_csv(input_file)

    Что делает: Библиотека pandas читает файл (например, Excel-таблицу, сохраненную как CSV) и загружает его в переменную data как таблицу (DataFrame).

python

    # В файле должны быть колонки Text1 и Text2
    results = []

    Что делает: Создает пустой список, куда мы будем складывать результаты обработки каждой строки таблицы.

python

    for _, row in data.iterrows():

    Что делает: iterrows() — это способ пройтись по каждой строке таблицы data.

        _ — это индекс строки (номер), нам он не нужен, поэтому ставим подчеркивание (так принято в Python).

        row — это сама строка таблицы (как словарь), из которой можно достать значения по имени колонки.

python

        text1 = str(row["Text1"])
        text2 = str(row["Text2"])

    Что делает: Достает значения из колонок с названиями "Text1" и "Text2".

    Зачем str()? На случай, если в таблице окажется число (например, 123), а не текст. Функция find_lcs работает только со строками, поэтому мы принудительно превращаем всё в строку.

python

        lcs = find_lcs(text1, text2)

    Что делает: Вызывает нашу первую функцию, чтобы найти общую подпоследовательность для этих двух конкретных текстов.

python

        results.append({
            "Text1": text1,
            "Text2": text2,
            "LCS": lcs,
            "LCS_Length": len(lcs)
        })

    Что делает: Создает словарь с результатами (исходные тексты, найденная подстрока и её длина) и добавляет его в список results.

python

    # Сохраняем результат
    result_data = pd.DataFrame(results)

    Что делает: Превращает наш список словарей results обратно в таблицу (DataFrame) с помощью pandas.

python

    result_data.to_csv(
        output_file,
        index=False,
        encoding="utf-8-sig"
    )

    Что делает: Сохраняет таблицу в файл CSV.

        output_file — имя файла.

        index=False — не сохранять номера строк (0, 1, 2...) в файл, они там не нужны.

        encoding="utf-8-sig" — важно, если в тексте есть русские буквы. Это кодировка, которую понимает Excel (без неё Excel может показать "кракозябры").

python

    print(result_data)
    print("\nРезультат сохранен в", output_file)

    Что делает: Просто выводит таблицу на экран и пишет сообщение, что всё сохранено.

Часть 3: Запуск
python

# Запуск программы
analyze_csv("input.csv", "result.csv")

    Что делает: Вызывает функцию analyze_csv, передавая ей имена файлов: читаем из input.csv, сохраняем в result.csv.
