# PythonLCS
14) НАИБОЛЬШАЯ ОБЩАЯ ПОДПОСЛЕДОВАТЕЛЬНОСТЬ (LONGEST COMMON SUBSEQUENCE)

Входные данные (Instance): конечный алфавит \(\Sigma\), конечное множество \(R\) строк, составленных из символов алфавита \(\Sigma\).

Решение (Solution): строка \(w \in \Sigma^*\), являющаяся подпоследовательностью каждой строки \(x \in R\). Это означает, что строку \(w\) можно получить из каждой строки \(x\), удаляя некоторые символы, не изменяя порядок оставшихся символов.

Критерий оценки (Measure): длина найденной подпоследовательности, то есть \(|w|\). Цель — найти подпоследовательность с максимально возможной длиной.



поиск наибольшей общей подпоследовательности — LCS
Задание №14
 «Наибольшая общая подпоследовательность» (Longest Common Subsequence, LCS) для набора строк.

 Нужно найти самую длинную последовательность символов, которая встречается в двух или нескольких строках в одинаковом порядке. При этом символы не обязаны стоять рядом.

Например:
- Строка 1: ABCBDAB
- Строка 2: BDCABA
- Одна из самых длинных общих подпоследовательностей: BCBA
- Длина: 4
